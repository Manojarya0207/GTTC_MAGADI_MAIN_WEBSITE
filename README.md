# GTTC Magadi - Official Website

The official web platform for the **Government Tool Room & Training Centre (GTTC), Magadi-36**. This website provides comprehensive information about the institution, its courses, admissions, placements, and campus amenities.

## 🚀 Overview

This project is a modern, responsive website designed to serve as a central hub for students, faculty, and prospective candidates of GTTC Magadi. It features a clean user interface, intuitive navigation, and detailed sections for various departments and academic activities.

## ✨ Features

- **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
- **Department Showcases:** Dedicated pages for DTDM, DMCH, DEEE, and DAIML departments.
- **Admission Portal:** Information on courses and a direct link to apply.
- **Academic Info:** Details about examinations and curriculum.
- **Placement Tracking:** Showcasing the career paths of graduates.
- **Interactive Gallery:** Visual tour of the campus and activities.
- **Search Functionality:** Quickly find relevant information across the site.
- **News Ticker:** Real-time updates and announcements.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons:** [Font Awesome](https://fontawesome.com/)
- **Typography:** Google Fonts (Roboto)

## 💻 How to Run

1. Clone the repository to your local machine.
2. Open `index.html` in any modern web browser.
3. No build step or installation is required as it uses vanilla technologies.
